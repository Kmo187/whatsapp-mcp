Connect to Claude

Add the MCP server to claude_desktop_config.json (or run claude mcp add), then restart the app.

{
  "mcpServers": {
    "whatsapp": {
      "command": "uv",
      "args": ["--directory", "/path/to/whatsapp-mcp/whatsapp-mcp-server", "run", "main.py"]
    }
  }
}
